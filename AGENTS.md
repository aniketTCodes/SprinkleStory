# Sprinkle Story workspace instructions

For all UI-related development, read and follow `UI_UX_GUIDE.md`. Maintain that guide alongside intentional changes to shared UI conventions. The frontend lives in `frontend/`; follow its `AGENTS.md` as well.

Frontend tasks must preserve all backend files and existing changes under `ims/`. Do not change backend code, configuration, or data to accommodate the UI unless the user separately authorizes that work.
